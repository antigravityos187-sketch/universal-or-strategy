Frequently Asked Questions

Does PTT Trade Copier require a chart to be open?
No. PTT runs as an Add-On at the NinjaTrader application level — not as a strategy or indicator. It works as long as NinjaTrader 8 is open and your accounts are connected. No chart, no strategy, no indicator required.
Does it work with Apex / TopStep / Rithmic?
Yes. PTT Trade Copier works with any account visible inside NinjaTrader 8. It has been validated on Apex Trader Funding, TopStep, and Rithmic/AMP connections. If your prop firm supports NT8, this works.
How fast does it copy orders?
On the same machine, copy latency is under 50 milliseconds — typically 10–20ms. It fires on the Order.OrderState == Submitted event, which is the earliest possible moment after you submit. Cross-machine or cross-broker copy depends on network and broker fill speed.
Can I copy to more than 3 follower accounts?
Yes. The multi-rule engine supports unlimited follower accounts per rule. Add as many as you like — each gets its own quantity multiplier and P&L cap setting.
What happens if my internet drops mid-trade?
The copy engine is event-driven — if an order event fires before the connection drops, it will copy. If the connection is down, no events fire. The license cache is stored locally for 7 days, so a network drop does not revoke your access.
Will it accidentally double-copy an order?
No. The dedup guard uses a 10-second TTL keyed to the order signature. If the same order triggers multiple events (e.g., retransmit), the second copy is detected and silently dropped.
Can I run multiple instruments at the same time?
Yes. Add one rule per instrument. Run MES on follower A, MNQ on follower B — all managed from the same Add-On window. Each rule can point to different master accounts if needed.
How does the P&L cap work?
Enter a negative number (e.g. -500) in the Daily P&L Cap field for a follower. When that account's realized P&L drops to or below that level, PTT silently stops sending orders to that account for the rest of the trading day. Other followers are unaffected. The cap resets at midnight (NT8 session reset).
What does "grandfathered for life" mean?
All v1 buyers — including WSGTA code buyers — receive every current feature and every future v1.x update forever, at no additional cost. If we introduce tier gating in v2 for new buyers, your license is unaffected. Your key never gets downgraded.
How do I update to a new version?
Download the new zip from the link in your purchase email (or request a new link from support), then re-import via Tools → Import NinjaScript Add-On. Your copy rules and license key are preserved. You do not need to re-enter your key.
Do you offer a trial?
We do not currently offer a free trial. Instead, we offer a 14-day money-back guarantee on lifetime licenses. If PTT Trade Copier doesn't work for your setup within 14 days, email us for a full refund. See our Refund Policy.
