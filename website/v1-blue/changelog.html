Changelog — PTT Trade Copier

Every release is tested on live accounts across multiple prop firms before shipping. 120+ [Fact] tests passing. Version numbering: v1.0 → v1.1 → v1.2 → v2.0. No "beta" label ever.

v1.0.0
2024 — Initial Release
Latest · Stable
Core Copy Engine
  • Event-driven order copy on submission — market and limit orders
  • Dedup guard with 10-second TTL prevents ghost copies on retransmit
  • Multi-rule engine — unlimited instruments and follower accounts
  • Per-rule enable/disable toggle persisted across restarts
  • Quantity multiplier per follower (e.g. 2x copies double size)
  • Daily P&L cap gate per follower — silently skips capped accounts
  • Rule persistence via XML — loads on NT8 startup automatically
Position Management
  • Shift+T — Trim ½ on master + all follower accounts simultaneously
  • Shift+F — Flatten all positions on master + all followers
  • Shift+C — Cancel all pending entry orders on master + all followers
  • Shift+B — Move stop to break-even (configurable inline buffer)
  • Auto-trail from break-even connected state
  • Global Quick Exit (QX-ALL) — emergency flatten across all rules and accounts
Advanced Features
  • ATR dynamic position sizing engine — risk-scaled quantities per follower
  • Click Trader — chart click places limit order at exact price on all accounts
  • Mirror Mode (Mode 2) — bracket entry/stop/target mirroring
  • Mode 1 — market order copy with fill confirmation
Infrastructure
  • Cryptolens license validation — remote verify on startup, 7-day offline cache
  • ConfuserEx obfuscation — symbol renaming, string encryption, anti-tamper
  • Standard NT8 zip import (Tools → Import NinjaScript Add-On)
  • Zero chart dependency — runs at Add-On level, not strategy level
  • Lock-free Actor/Enqueue architecture — zero blocking on NT8 UI thread
Build quality: Built across 120+ engineering sessions (B1–B120). 120+ [Fact] unit tests passing. Validated on Apex Trader Funding, TopStep, and Rithmic/AMP connections. Cyclomatic complexity ≤ 8 on all hot-path methods (Jane Street engineering standard).
