Features

Everything you need to run multiple prop accounts

Built for traders juggling evaluation accounts across Apex, TopStep, and Rithmic — where a missed copy or a blown daily limit costs real money.

Instant Order Copy
Market and limit orders copy to all follower accounts the moment you submit on the master — no polling, event-driven.
Multi-Rule Engine
Copy different instruments to different accounts simultaneously. Run MES on one follower, MNQ on another — one window manages all.
Daily P&L Cap Gate
Set a daily loss limit per follower. When the cap is hit, that account is silently skipped — your other accounts keep running.
Trim + Flatten Hotkeys
Shift+T trims half. Shift+F flattens. Shift+B moves stop to break-even. All hotkeys fire on master AND every follower simultaneously.
ATR Dynamic Sizing
Automatically scale quantity per follower based on ATR-derived risk. Each account gets the right size for its drawdown rules.
Click Trader
Click any price level on your chart — a limit order is placed at exactly that price on master and all followers instantly.
Mirror Mode
Full bracket mirroring — entry, stop, and target all replicate. Works in both Mode 1 (market copy) and Mode 2 (bracket mirror).
Global Quick Exit
One button flattens every account across every rule simultaneously. Essential for prop firm risk events.
Rule Persistence
Your copy rules are saved to XML and reload automatically on NT8 restart. Zero configuration on reopen.
Setup

Running in under five minutes

No installer. No server. No third-party account. NinjaTrader Trade Copier runs entirely inside NinjaTrader 8.

01
Import the zip
Tools Import NinjaScript — select NinjaTrader-TradeCopier-v1.0.zip. NT8 compiles it automatically. No installer.
02
Open the Add-On window
Tools Add-Ons NinjaTrader Trade Copier. Enter your license key once.
03
Add a copy rule
Select master account, follower accounts, instrument, quantity multiplier, enable. Click Add Rule.
04
Trade normally
Place orders on your master account as usual. Every follower receives the same order in milliseconds.
