Install Guide

Get up and running in
under 5 minutes

NinjaTrader Trade Copier installs as a standard NinjaTrader 8 Add-On via the built-in zip import. No installer, no admin privileges, no chart open. Follow the steps below.

Requirements

NinjaTrader 8

NT8 version 8.0.23 or later. Free platform — download from ninjatrader.com.

A license key

Purchase from the Pricing page. Your key is emailed within 60 seconds of payment.

Windows 10 / 11

NT8 is Windows-only. 64-bit required. .NET Framework 4.8 is bundled with NT8.

At least 2 connected accounts

A master account and at least one follower — both connected in NT8 before you create a rule.

Phase 1 — Install the Add-On
1
Download the zip file
After payment, check your email for a message from LemonSqueezy / Prop Trader Tools. It will contain a download link for NinjaTrader-TradeCopier-v1.0.zip. Save the file anywhere — your Desktop is fine.
Tip: Do not unzip the file. NT8 reads the zip directly.
2
Open the Import dialog in NT8
With NinjaTrader 8 open, click the top menu bar:

Tools → Import NinjaScript Add-On…

A file picker will open.
3
Select the zip file
Navigate to where you saved NinjaTrader-TradeCopier-v1.0.zip and click Open. NinjaTrader will compile the Add-On automatically. You will see a confirmation dialog when it succeeds.
If compilation fails: Make sure you are on NT8 version 8.0.23 or later. Go to Help → Check for Updates. Then retry the import.
4
Restart NinjaTrader (first install only)
NT8 requires a restart after a new Add-On import. Click OK on the confirmation and restart. You do not need to restart for future updates — only the first install.
Phase 2 — Enter Your License Key
5
Open the NinjaTrader Trade Copier window
After restart, go to:

Tools → Add-Ons → NinjaTrader Trade Copier

The Add-On window opens. You will see a License Key field at the top.
6
Paste your license key and activate
Copy the license key from the email you received. Paste it into the License Key field and click Activate. The Add-On contacts the Cryptolens server to verify your key. On success, the status bar turns green and shows your tier.
Offline: After first activation, the key is cached locally for 7 days. NT8 does not need internet access after the initial validation.
Phase 3 — Create Your First Copy Rule
7
Connect your accounts in NT8
Make sure both your master account and all follower accounts are connected. Go to Connections → Manage Connections to verify. NinjaTrader Trade Copier works with any account visible in NT8 — Apex, TopStep, Rithmic, any broker.
8
Add a copy rule
In the NinjaTrader Trade Copier window, click Add Rule. Fill in:
  • Master Account — the account whose orders will be copied
  • Follower Accounts — check each account to receive copies
  • Instrument — e.g. MES 09-25 or leave blank to copy all instruments
  • Qty Multiplier — e.g. 1.0 copies 1:1; 2.0 doubles the quantity on followers
  • Daily P&L Cap — optional; enter a negative number (e.g. -500) to halt copying when that account hits the limit
9
Enable the rule and trade
Toggle the rule to Enabled. The status indicator turns green. Place an order on your master account — you will see the same order appear on all follower accounts within milliseconds. Your rules persist across NT8 restarts automatically.
That's it. No chart needs to be open. NinjaTrader Trade Copier runs at the Add-On level — always active as long as NT8 is running.

Troubleshooting
Orders are not copying
Check that the rule is Enabled (green indicator). Verify both accounts are connected in NT8 — go to Connections → Manage Connections. If using a P&L cap, verify the follower account has not hit its daily limit.
License key shows invalid
Ensure you are connected to the internet for first-time activation. Copy-paste the key exactly from your email — no extra spaces. If the problem persists, email support@proptradertools.com with your order number.
Compilation error on import
Update NT8 to the latest version (Help → Check for Updates). Then retry: Tools → Import NinjaScript Add-On. If the error persists, send the NT8 log from Documents\NinjaTrader 8\log\ to support.
Add-On window does not appear in Tools menu
Restart NT8 after the import. Add-Ons require a full restart to appear in the Tools menu on first install. Check Tools → Add-Ons (not Tools → Import).
