How It Works

Up and running in under 5 minutes

1

Import the zip into NinjaTrader

Tools → Import NinjaScript → select NinjaTrader-TradeCopier-v1.0.zip. NT8 compiles it automatically. No installer.

2

Open the Add-On window

Tools → Add-Ons → NinjaTrader Trade Copier. Enter your license key once. The window shows your copy rules and status.

3

Add a copy rule

Select master account → follower accounts → instrument → quantity multiplier → enable. Click Add Rule.

4

Trade normally

Place orders on your master account as usual. Every follower receives the same order in milliseconds — automatically.

No chart required

Unlike strategy-based copiers, NinjaTrader Trade Copier runs as an Add-On at the NinjaTrader application level. No charts need to be open. Works the moment NT8 connects to your broker.
