Core Capabilities

Everything You Need to Scale

Instant Order Copy

Event-driven, no polling — fires on fill. Orders reach all follower accounts within milliseconds of the leader fill event.

Multi-Rule Engine

Route different instruments to different accounts simultaneously. One leader can drive unlimited rules with independent instrument and multiplier settings.

Daily P&L Cap Gate

Silent skip when a follower hits its daily loss cap. Other accounts keep running uninterrupted — no global halt, no manual intervention required.

Trim + Flatten Hotkeys

Shift+T trims half, Shift+F flattens all, Shift+B moves stop to break-even. Single keystrokes execute across every active follower account instantly.

Quantity scaled per follower by ATR-derived risk. Each account sizes positions according to current volatility, not a fixed multiplier.

Mirror Mode

Global Quick Exit

Setup Process

Up and Running in Minutes

No separate server, no cloud subscription, no broker API keys. Everything runs inside NinjaTrader.

Step 01

Import the Zip

Tools → Import NinjaScript → NinjaTrader-TradeCopier-v1.0.zip. The add-on installs directly into your NinjaTrader environment.

Step 02

Open the Add-On Window

Tools → Add-Ons → NinjaTrader Trade Copier. Enter your license key to activate. The panel opens immediately.

Step 03

Add a Copy Rule

Select master account → followers → instrument → multiplier → enable. Each rule is independent and configurable.

Step 04

Trade Normally

Followers receive every order in milliseconds. No change to your trading workflow required. Just trade your leader account as usual.
